# Exercício 2

Escreva um programa que calcule o produtório abaixo. O valor de n deve ser lido
da posição 0x10010000 da memória no início do programa. O valor de A deve ser
escrito na memória no fim do programa, na posição 0x10010004.

OBS: considere a divisão inteira, i.e.:
1 / 2 = 0,
2 / 2 = 1,
3 / 2 = 1,
4 / 2 = 2, etc.
